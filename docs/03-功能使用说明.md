# 03 - 功能使用说明

## 命令行（CLI）

入口：`python -m freeproxypool <子命令>`，或安装后的 `freeproxypool <子命令>`。

```bash
python -m freeproxypool --help          # 查看全部子命令
python -m freeproxypool --version       # 查看版本
```

### server — 启动 API 网关

启动 FastAPI 网关，含代理分发、管理后台、健康检查、指标。

```bash
python -m freeproxypool server
```

监听地址由 `HOST` / `PORT` 配置决定（默认 `0.0.0.0:5020`）。可多副本部署（前置 Nginx 统一入口）。

### collector — 启动采集服务

扫描采集源 → 过滤去重 → 推入待验队列。无状态，可多副本。

```bash
python -m freeproxypool collector
```

### validator — 启动验证服务

消费待验队列 → 三层递进验证 → 写入有效池。无状态，可多副本。

```bash
python -m freeproxypool validator
```

### scheduler — 启动调度服务

存量复检 / 数据清理 / 统计告警 / 手动触发。**单副本**，多副本会重复执行。

```bash
python -m freeproxypool scheduler
```

### all — 单进程运行全部（本地调试）

单进程同时跑 collector / validator / scheduler / gateway。**仅调试用**，生产请分进程部署。

```bash
python -m freeproxypool all
```

### selftest — 离线自检

运行内置自检套件，不依赖 Redis / MySQL，不产生网络请求。覆盖版本一致性、输入校验、脱敏、密码、配置中心 fail-closed、存储层、队列、分发策略、网关鉴权链路、采集源熔断、延迟分层等。

```bash
python -m freeproxypool selftest
```

请安装开发依赖后从完整项目源码运行。全部通过返回 0，用例失败返回 1，缺少源码返回 2。

### version — 打印版本与运行信息

```bash
python -m freeproxypool version
# 输出：FreeProxyPool 0.1.0 / Python 版本 / 平台
```

### config — 打印当前生效配置

密码类只显示是否已设置，不回显明文。

```bash
python -m freeproxypool config
```

### check — 单代理深度诊断

诊断单个代理，输出 TCP / HTTP / HTTPS 分层延迟、出口 IP、匿名度、地域与最终判定
（`excellent` / `limited` / `unusable`）。

```bash
python -m freeproxypool check 1.2.3.4:8080
python -m freeproxypool check 1.2.3.4:8080 --json          # JSON 输出，便于脚本消费
python -m freeproxypool check 1.2.3.4:1080 --protocol socks5
python -m freeproxypool check 1.2.3.4:8080 --no-region      # 跳过地域解析
```

| 参数 | 说明 |
|------|------|
| `proxy` | 代理地址（`ip:port`，必填） |
| `--json` | 以 JSON 输出 |
| `--http-url` | HTTP 探针目标（默认取配置 `HTTP_URL`） |
| `--https-url` | HTTPS 探针目标（默认取配置 `HTTPS_URL`） |
| `--timeout` | 单次探针超时（秒，默认 10） |
| `--protocol` | 代理传输协议：`http` / `socks4` / `socks5`（默认 `http`） |
| `--no-region` | 跳过地域解析 |

## API 接口

开启 `API_KEY` 后，所有分发与运维接口均需携带请求头 `API-KEY: <key>`。
交互式文档：`http://<host>:5020/docs`。

### 分发接口

| 接口 | 参数 | 说明 |
|------|------|------|
| `GET /get/` | `type=https`, `area=CN`, `strategy=latency\|random\|roundrobin\|weighted`, `anon=elite\|anonymous\|transparent`, `tier=fast\|medium\|slow`, `protocol=http\|socks4\|socks5`, `format=json\|text` | 获取一个代理 |
| `GET /batch/` | `n=10` + 同上筛选参数 | 批量获取（最多 `BATCH_MAX` 条） |
| `GET /pop/` | `type=https`, `anon=elite`, `protocol=socks5`, `format=json\|text` | 获取并从池中删除一个代理 |
| `GET /all/` | `type=https`, `area=CN`, `anon=elite`, `tier=fast`, `protocol=socks5`, `format=json\|text` | 获取代理列表 |
| `GET /subscribe/clash` | `key=API_KEY` + 同上筛选参数（`format` 不适用） | Clash/Mihomo 订阅输出（YAML，http/socks5 节点组） |
| `GET /subscribe/v2ray` | `key=API_KEY` + 同上筛选参数 | V2Ray/v2rayN 订阅输出（base64 分享 URI） |

示例：

```bash
KEY="你的密钥"
curl -H "API-KEY: $KEY" "http://localhost:5020/get/"
curl -H "API-KEY: $KEY" "http://localhost:5020/get/?type=https&area=CN&strategy=latency"
curl -H "API-KEY: $KEY" "http://localhost:5020/get/?tier=fast"
curl -H "API-KEY: $KEY" "http://localhost:5020/get/?protocol=socks5"
curl -H "API-KEY: $KEY" "http://localhost:5020/batch/?n=20&tier=medium"
curl -H "API-KEY: $KEY" "http://localhost:5020/all/?format=text"
```

### 订阅输出（Clash / V2Ray 客户端接入）

把代理池整体接入 Clash / V2RayN / v2rayNG 等客户端：在客户端里把下面的
订阅 URL 配成"订阅链接"，即可自动同步池内全部可用代理为一个节点组
（名称 `FreeProxyPool`），池子随采集/校验自动更新：

| 订阅 URL | 用途 |
|----------|------|
| `http://<host>:5020/subscribe/clash?key=<API_KEY>` | Clash / Mihomo（`proxies` + `FreeProxyPool` 节点组，`mode: rule`） |
| `http://<host>:5020/subscribe/v2ray?key=<API_KEY>` | V2Ray / v2rayN / v2rayNG（base64 分享 URI） |

说明：

- 鉴权与 `/all/` 同级：`API_KEY` 用 query 参数 `key=` 传递（订阅工具通常
  无法自定义请求头），也可照常使用 `API-KEY` 请求头；
- 筛选参数（`type` / `area` / `anon` / `tier` / `protocol` / `exclude_dnsbl`）
  与 `/all/` 完全一致，可用于生成地域/协议子集订阅；
- **SOCKS4 代理不被输出**：Clash/Mihomo 无 socks4 节点类型，v2rayN 的
  `socks://` 分享按 SOCKS5 解析——硬塞只会生成死节点，如实跳过；
- 输出条数受 `ALL_MAX` 约束（默认 200），与 `/all/` 同源。

### 运维接口

| 接口 | 说明 |
|------|------|
| `GET /count/` | 代理池统计（含 tier / protocol 分布） |
| `GET /delete/?proxy=ip:port` | 删除指定代理 |
| `POST /report/` | 回报失效代理（`{"proxies":["1.2.3.4:8080"]}`），服务端立即剔除并拉黑 |
| `GET /stats/` | 精简运行统计 |
| `GET /health` | 健康检查（含 `/health/live` 纯存活探针） |
| `GET /metrics` | Prometheus 指标（默认需 API Key） |
| `GET /version` | 版本信息（无需鉴权） |

```bash
curl -H "API-KEY: $KEY" "http://localhost:5020/count/"

# 客户端发现代理失效 → 回报，服务端立即剔除并拉黑
curl -X POST -H "API-KEY: $KEY" -H "Content-Type: application/json" \
     -d '{"proxies":["1.2.3.4:8080","5.6.7.8:3128"]}' \
     "http://localhost:5020/report/"

curl "http://localhost:5020/health"
curl "http://localhost:5020/version"
curl -H "API-KEY: $KEY" "http://localhost:5020/metrics"
```

### 管理后台

访问 `http://<host>:5020/admin`，使用 `ADMIN_PASSWORD` 登录。后台提供：概览、配置管理（热更新）、采集源管理（启停/URL 覆盖）、代理池管理（查看/清理/拉黑）、日志查看、告警查看、手动触发任务、单代理诊断等。

后台 API 前缀 `/admin/api/*`，写操作需 CSRF 令牌（`X-CSRF-Token` 请求头）。`ADMIN_ENABLED=0` 时整个 `/admin` 前缀不可用。

## 客户端 SDK

SDK 位于 `src/freeproxypool/sdk/`，**不依赖项目内任何模块**，外部调用方拷走 `sdk/` 一个目录即可使用。提供同步（`requests`）与异步（`aiohttp` + `aiohttp-socks`）两个客户端，自动带 API Key、自动回报失效代理、指数退避重试。

### 同步客户端

```python
from freeproxypool.sdk import ProxyPoolClient

pool = ProxyPoolClient("http://127.0.0.1:5020", api_key="你的密钥")

# 取一个代理
proxy = pool.get_proxy(type="https", area="CN")
print(proxy["proxy"])

# 经代理发请求（自动回报失效代理）
resp, proxy = pool.fetch("https://example.com")
print(resp.status_code, proxy["proxy"])

# 批量取
proxies = pool.batch(n=10, tier="fast")

# 获取全池列表
all_proxies = pool.all(format="text")

# 回报失效代理
pool.report(["1.2.3.4:8080"])

pool.close()
```

主要方法：

| 方法 | 说明 |
|------|------|
| `get_proxy(**filters)` | 取一个代理，池空或无匹配返回 `None` |
| `batch(n=10, **filters)` | 批量取代理 |
| `all(**filters)` | 获取代理列表 |
| `fetch(url, **filters)` | 经代理请求目标，返回 `(响应, 代理)`，自动回报失效代理 |
| `report(proxies)` | 回报失效代理（失败不影响主流程） |
| `close()` | 关闭会话 |

> SOCKS 代理：同步客户端使用 SOCKS 需安装 `PySocks`（`pip install 'requests[socks]'`）。

### 异步客户端

```python
import asyncio
from freeproxypool.sdk import AsyncProxyPoolClient

async def main():
    pool = AsyncProxyPoolClient("http://127.0.0.1:5020", api_key="你的密钥")
    resp, proxy = await pool.fetch("https://example.com")
    print(resp.status, proxy["proxy"])
    await pool.close()

asyncio.run(main())
```

异步客户端走 `aiohttp-socks`，SOCKS 代理无需额外依赖。

## Scrapy 集成示例

`src/freeproxypool/examples/scrapy_middleware.py` 提供 Scrapy 下载中间件范例，代理失效即回报。

在 Scrapy 项目的 `settings.py` 中启用：

```python
DOWNLOADER_MIDDLEWARES = {
    "freeproxypool.examples.scrapy_middleware.ProxyPoolMiddleware": 543,
}

FPP_API_KEY = "你的密钥"
FPP_BASE_URL = "http://127.0.0.1:5020"
```

> 若未安装 freeproxypool 包，可将 `examples/scrapy_middleware.py` 与 `sdk/` 一起拷入 Scrapy 项目，
> 相应调整中间件的导入路径。

## 每日质量快照工具

`src/freeproxypool/tools/daily_snapshot.py` 生成"昨日可用代理清单"参考产物。

```bash
# 直读 Redis（生产机 cron 跑最省事，不需要 API Key）
python -m freeproxypool.tools.daily_snapshot --out-dir snapshot

# 走 API（顺便验证 SDK 可用）
python -m freeproxypool.tools.daily_snapshot --base-url http://127.0.0.1:5020 \
    --api-key "$API_KEY" --out-dir snapshot
```

产物：`snapshot.json`（全量快照）、`all.txt`（一行一个 `ip:port`）、`<CODE>.txt`（按国家分文件）、`index.html`（静态看板）。产物不含任何凭据。

## 分层 CI 门禁工具

`src/freeproxypool/tools/ci_gate.py` 提供分层门禁（lint / test / audit / build），按改动路径决定跑哪些层。运行检查需要完整项目源码，`--list` 可直接查看规则。

```bash
python -m freeproxypool.tools.ci_gate                 # 跑全部层
python -m freeproxypool.tools.ci_gate --layers lint,test
python -m freeproxypool.tools.ci_gate --paths a.py b.md
python -m freeproxypool.tools.ci_gate --list          # 列出层与触发规则
```

## 已知限制

- `scheduler` 不可多副本，多副本会重复执行存量复检、清理与告警。
- 同步 SDK 使用 SOCKS 代理需额外安装 `PySocks`；异步 SDK 无此限制。
- 地域索引不可用时自动退回全表扫描，但地域筛选始终严格匹配（只改取数方式，不改返回结果）。
- 采集源为公开免费代理，可用性与质量不保证，仅供学习与自有测试。
